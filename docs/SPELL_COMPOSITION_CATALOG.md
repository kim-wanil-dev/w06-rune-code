# 노드 연결 마법 조합 목록

기준일: 2026-10-10

현재 룬 문법과 실행 코드를 살펴보고, 이미 지원되는 연결 방식으로 만들 수 있는 마법 조합을 용도별로 정리한다. 아래 조합은 설계 예시이며 새 템플릿 자산으로 저장하거나 개별 컴파일·밸런스 검증을 한 것은 아니다.

## 현재 구조에서 확인한 조합 방식

| 연결 방식 | 현재 동작 | 설계상 이름 |
|---|---|---|
| 형태 `shape.*`의 `next` → 행동 `behavior.*` | 형태와 속성 선택값, 행동을 하나의 전투 효과로 정규화한다. 예: 구형+화염+발사 = 화염 투사체 | **효과 조립** |
| `spell.call` 실행 입력 → 보관함 마법 ID | 저장된 그래프의 실행 트리를 불러와 현재 시전 흐름에서 실행한다. 호출 마법의 발동 조건은 다시 검사하지 않는다. | **마법 호출** |
| 형태·호출의 `onHit`, `onExpire`, `onFirstHitOrExpire` → 후속 실행 노드 | 투사체나 효과의 이벤트 위치·방향·대상을 후속 실행 문맥에 넘긴다. `onHit`는 적중마다, `onFirstHitOrExpire`는 만들어진 각 투사체의 첫 적중 또는 소멸 때 실행된다. | **연쇄 시전** |
| `flow.delay`, `flow.repeat`, `flow.if` → 실행 노드 | 실행 시점을 늦추거나 반복하고 조건을 만족할 때만 다음 마법을 실행한다. 현재 `flow.if`의 `else` 포트는 지원 중단 상태다. | **마법 흐름 제어** |
| Modifier의 `mod` → 행동 또는 `spell.call` | 피해·범위·속도·지속시간, 관통·유도·다중 발동 등을 바꾼다. 지원되지 않는 대상 조합은 붙어 있어도 효과가 적용되지 않을 수 있다. | **마법 강화** |

### 이름 제안

- 전체적으로 노드를 조합해 새 주문을 설계하는 활동은 **마법 합성**이라고 부른다.
- 저장된 다른 그래프를 실행하는 `spell.call`의 현재 표시 이름은 **마법 메소드**다. 플레이어에게는 동작이 바로 보이는 **마법 호출**로 바꾸는 편을 권한다.
- 명중·소멸 같은 사건 뒤에 다른 효과를 잇는 연결은 **연쇄 시전**이라고 부른다.
- 형태와 행동을 연결해 한 효과를 만드는 것은 **효과 조립**이라고 부르면, 주문 전체의 합성과 구분하기 쉽다.

## 조합 예시

표기에서 `→`는 실행 연결, `─next→`는 형태-행동 체인, `─mod→`는 강화 연결이다. `+`는 같은 실행 출력에서 두 행동 노드로 분기한다. 대괄호 값은 노드 파라미터다. `마법 호출[이름]`은 보관함의 해당 그래프를 선택한다.

### 공격·제압

| 마법 이름 | 그래프 조합 | 용도와 활용 |
|---|---|---|
| **화염 관통창** | 시전[공격] → 구형[화염] ─next→ 발사 ─mod→ 관통 | 일렬로 선 적을 관통해 함께 태운다. 좁은 통로나 보스의 직선 진입을 응징할 때 쓴다. |
| **추적 빙결탄** | 시전[공격] → 구형[얼음] ─next→ 발사 ─mod→ 유도 | 빠르게 움직이는 우선 표적을 쫓아 냉기 상태를 쌓는다. 명중률이 필요한 정예 적 대응용이다. |
| **전격 산탄** | 시전[공격] → 부채꼴[전격] ─next→ 발사 ─mod→ 다중 | 전방 넓은 각도로 여러 발을 흩뿌리고, 맞은 적의 전격 연쇄로 가까운 적까지 압박한다. 다중 등급에 따라 탄 수와 자원 부담이 달라진다. |
| **전격 파쇄파** | 시전[공격] → 부채꼴[전격] ─next→ 폭발 ─mod→ 확장 | 전방 군집을 한 번에 밀어내듯 타격한다. 발사체 조준을 맞추기 어려운 근거리 다수전에 적합하다. |
| **빙결 잔류장** | 시전[공격] → 부채꼴[얼음] ─next→ 잔류 ─mod→ 확장, 지속시간 | 정면의 접근 경로를 일정 시간 냉기 지대로 막는다. 적이 몰려오는 방향을 제한하거나 냉기 누적을 돕는다. |
| **공전 냉기륜** | 시전[공격] → 구형[얼음] ─next→ 공전 ─mod→ 지속시간 | 플레이어 주변으로 도는 효과가 접근하는 적을 반복해서 견제한다. 포위되기 쉬운 상황에서 이동과 함께 사용한다. |

### 타이밍·조건부 조합

| 마법 이름 | 그래프 조합 | 용도와 활용 |
|---|---|---|
| **삼연 점사** | 시전[공격] → 반복[3회, 0.15초] ─body→ 마법 호출[파이어 볼트] | 기본 투사체를 짧은 간격으로 세 번 발사한다. 순간 화력을 높이지만 회차마다 호출 마법 비용이 들고, 같은 속성·형태를 반복하면 적응이 쌓일 수 있다. |
| **지연 기폭진** | 시전[공격] → 지연[0.5초] → 마법 호출[충격파] | 같은 방향의 고정 지점에 폭발을 늦춰 배치한다. 호출 위치와 방향은 예약 시점의 실행 문맥을 따르므로, 적을 추적하는 지연 폭발은 아니다. |
| **명중 후 폭발** | 시전[공격] → 마법 호출[파이어 볼트] ─onHit→ 마법 호출[충격파] | 첫 투사체의 적중 문맥을 이어 후속 범위 공격을 낸다. 충격파 중심은 템플릿의 거리 오프셋만큼 더 전방에 놓인다. 첫 주문이 여러 적을 관통하면 적중마다 후속 폭발이 생길 수 있으므로 비용을 확인한다. |
| **빗나감 보정 탄두** | 시전[공격] → 마법 호출[파이어 볼트] ─onExpire→ 마법 호출[충격파] | 투사체가 적을 맞히지 못하고 소멸할 때 마지막 위치에서 폭발한다. 명중 시에는 소멸 분기가 실행되지 않아 빗나간 사격의 손실을 줄인다. |
| **저체력 마무리** | 시전[공격] → 마법 호출[파이어 볼트] ─onHit→ 조건[대상 HP 30% 이하] ─then→ 마법 호출[충격파] | 적중 대상의 체력이 낮을 때만 후속 주문을 쓴다. 조건 실패 시 다른 분기는 실행되지 않는다. |

### 생존·회복

| 마법 이름 | 그래프 조합 | 용도와 활용 |
|---|---|---|
| **비상 자기수복막** | 시전[피격] → 조건[자신 HP 50% 이하] ─then→ 적용[회복, 위력 설정] + 적용[보호, 위력·지속시간 설정] | 위험 구간에서 자신을 회복하고 보호막도 부여한다. 현재 미션 전투는 활성 슬롯 하나만 시전하므로, 두 효과를 모두 쓰려면 한 그래프의 같은 조건 분기에 연결한다. |

## 구현·사용 범위 메모

- 기본 보관함 템플릿은 `firebolt`, `shockwave`, `triplefire`, `magic_missile`, `barrier` 다섯 개다. 현재 다섯 템플릿 자체에는 `spell.call`을 이용한 복합 호출 예제가 없다.
- 코드에는 보관함 마법 선택 UI, 중첩 그래프 컴파일, 호출 순환 거부, 호출부 Modifier와 호출 이벤트 전달 경로가 있다. 따라서 **엔진 기능은 존재하지만 기본 템플릿에서 활용법을 보여주지는 않는다.**
- 시작 룬은 구형·사각·부채꼴·발사와 일반 속성이다. 화염·얼음 등 나머지 속성, 행동, 강화 룬, 흐름 제어, 마법 호출은 해금이 필요하다. 조합을 만들기 전에 필요한 룬을 트리에서 해금해야 한다.
- 형태의 속성은 현재 별도 속성 노드를 연결하는 방식이 아니라 형태 노드의 `element` 파라미터에서 선택한다. Modifier는 행동 또는 마법 호출의 `mod` 포트에 연결한다.
- 호출 그래프는 서로 재사용할 수 있지만 자기 자신으로 돌아오는 직접·간접 순환 호출은 거부된다. 반복은 `flow.repeat`로 구성한다.
- `onHit`는 대상별 적중 이벤트마다 실행되므로 관통·다중 발사와 합치면 후속 주문 수와 에너지 비용이 크게 늘 수 있다. 비용과 최대 실행·개체 제한은 컴파일 결과에서 확인한다.
- 이 문서에는 설계 목록만 추가했다. 새 룬, 그래프 템플릿 자산, 테스트 코드는 추가하지 않았고 제안 조합의 실제 전투 밸런스는 아직 확인하지 않았다.
